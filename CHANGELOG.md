# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-02

### Added
- Enterprise Urban Air Mobility (UAM) SaaS Command Platform.
- Core React 19 Frontend with Tailwind CSS v4 styling.
- Role-Based Access Control (RBAC) supporting Executive, Operations, Fleet, and Safety roles.
- Interactive SVG Mumbai Airspace Map with real-time vector overlay.
- Server-side Express proxy for AI Copilot (`@google/genai`).
- Multi-theme support including True-Black OLED tactical theme.
- Dynamic scenario simulator (Weather, Congestion, Emergencies).
- Power BI DAX builder export capability.
- Full TypeScript 5.8 strict typing integration.
- Accessibility compliance tuning (WCAG AA+).

### Fixed
- Stabilized esbuild configuration for single-file deployment (`dist/server.cjs`).
