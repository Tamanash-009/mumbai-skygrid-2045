# Contributing to Mumbai SkyGrid 2045

First off, thank you for considering contributing to Mumbai SkyGrid 2045. It's people like you that make it a great platform for the future of urban air mobility.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an [issue](https://github.com/Tamanash-009/mumbai-skygrid-2045/issues) covering it. If not, feel free to open a new one!

## Fork & create a branch

If this is something you think you can fix, then fork Mumbai SkyGrid 2045 and create a branch with a descriptive name.

## Get the test suite running

Make sure your development environment is set up and all linting/build tasks pass. We strictly enforce `npm run typecheck` and `npm run lint`. 

## Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Mumbai SkyGrid 2045's master branch.

Once your branch is up to date, you're ready to make a Pull Request!
